# 节点市场数据包协议 v4.0.0

持仓与候选池的结构化数据由本地程序采集，**不得交给 LLM 拉取、重试或补造**。定时任务先用 MCP `analysis_protocol_get` 取得协议，再调用 `node_packet_get(node="HH:MM", include_intraday=true, persist=true)`；不得使用 Shell，人工调试才可使用同名 CLI。

## 程序采集和计算

1. 腾讯一次批量获取全部持仓、候选和上证/深证/沪深300报价。主源完整、新鲜且字段合规时立即停止，不调用其他报价源；仅对缺失、异常或超过90秒的股票调用东方财富备用。一个合规来源且 `tradeable=true` 即可生成精确指令。
2. 腾讯分时优先、东方财富分时备用，并发获取。数据包保留压缩后的价格路径并在本地计算 VWAP、相对VWAP、5/15/30分钟收益、斜率、趋势效率、区间位置、冲高回落/探底回升、最大回撤和近5分钟量能加速度。
3. 腾讯前复权日K并发获取，每个自然日只首次联网，之后读本地缓存；首次冷DNS失败允许一次有界重试。本地计算 MA5/10/20/60、均线排列、5/10/20日收益、ATR14、20日高低点距离、5/20日均量、估算量比及持仓期最高收盘。
4. 本地结合指数计算个股相对沪深300的日内与5日超额，给候选池生成日内、5日及相对强弱排名。候选原有评分拆分、催化、风险、支撑/压力/失效价和动态距离均随包提供。
5. 每个来源记录 `elapsed_ms`、缓存命中、重试恢复和未恢复标的。失败缓存强制标记陈旧；不得把缺失的市场广度、板块资金或新闻编造成事实。

## Agent 使用规则

- 唯一结构化事实：`market_context`、`account`、`watchlist`、`instruments`、`source_health`、`summary.feature_coverage` 和 `packet_path`。
- 允许：只查本节点以来的公司/交易所公告和少量权威消息增量；结合策略解释数据并提出人工执行建议。
- 禁止：另查报价、K线、指数、分时、板块或资金流；因缺少第二来源而降级；用聊天记忆覆盖数据包。
- 报价为 `stale_or_invalid`、`cached` 或 `unavailable` 时，只能观察，不能创建依赖该价的精确委托。某项非关键特征缺失不终止整轮分析，要明确降低哪部分置信度。
- `analysis_run_record` 必须引用 `packet_path`，保存数据健康、关键事实、逐股判断、反方证据、场景计划、最终动作和下一触发条件。
