# 盘中监控协议 v5

监控程序是低成本触发器，不是交易策略或自动下单器。

- 只能监控当前持仓或候选池股票；每轮分析后由 Agent 重新选择模板、股票、指标、阈值、重置距离、冷却时间和到期时间。
- 阈值必须来自本轮证据（支撑、压力、失效价、VWAP 偏离或相对沪深300强弱），不能随意凑数。
- 使用跨越触发、冷却和 rearm，避免价格停在阈值一侧时重复唤醒。
- 监控快照只拉取腾讯行情。字段不可用时记录 unavailable，不得自动换源。
- 信号出现只令 `analysis_runtime_poll` 返回 `monitor_signal`；完整分析后才可能产生严格格式的人工执行建议。
- 没有值得监控的条件时提交空 monitors，并写明理由。
