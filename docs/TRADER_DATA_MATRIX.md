# Human-trader data matrix

“像人类交易员分析”不等于输出更长，而是同时具备市场背景、标的状态、持仓语境、相对比较、反方证据和条件化行动。下表是节点级最小数据合同。

| 分析需要 | 旧数据包 | v4 数据来源/计算 | 状态 |
|---|---|---|---|
| 最新价、昨收、开高低、量额、时间 | 有 | 腾讯批量报价；东方财富只按需兜底 | 已补齐并标准化单位 |
| 买一卖一、换手、振幅、跳空、区间位置 | 无/部分 | 腾讯字段 + 本地计算 | 已补齐，字段缺失可降级 |
| 完整日内路径与关键拐点 | 只保留点数和末价 | 腾讯分时；向 Agent 提供24点压缩路径 | 已补齐 |
| VWAP、5/15/30分钟动量、斜率、回撤、量能加速 | 无 | 分时累计量额和路径本地计算 | 已补齐 |
| MA5/10/20/60、ATR、5/10/20日收益、20日区间、量比 | 无 | 腾讯120根前复权日K + 本地计算 | 已补齐；按日缓存 |
| 大盘环境 | 无 | 上证、深证、沪深300同批报价与日K | 已补齐；注明是指数代理 |
| 个股相对大盘强弱 | 无 | 个股减沪深300的日内/5日收益 | 已补齐 |
| 持仓成本、浮盈亏、可卖数、持仓期高点 | 仅成本和股数 | 账户状态 + 当前价 + 日K | 已补齐 |
| 候选评分拆分、催化、风险、原始失效逻辑 | 代码中被丢弃 | 本地候选池归档字段 | 已补齐 |
| 候选动态价位距离与池内排名 | 无 | 当前价、本地技术指标和候选参数计算 | 已补齐 |
| 全市场涨跌家数、实时行业广度、主力资金 | 无 | 需要额外市场级数据源 | 非阻塞可选；当前不得臆造 |
| 最新公告/权威消息 | 由LLM搜集 | 公司/交易所公告优先，少量增量 | 保留给 Agent |

## VPN latency observations

2026-08-06 在开启 VPN 的 Windows 环境测试：腾讯5至9标的批量报价热连接约161–377ms，单股分时约179–301ms，单股120日K约234–244ms。旧运输链在冷DNS失败后叠加 `urllib` 等待，完整首轮曾达到41.8s；改为硬超时单运输链路并启用日K缓存后，完整后续节点实测约0.85s。当天首次日K冷启动允许一次有界并发重试，失败标的会显式进入数据健康，不会无限等待。

这些数字是环境观测，不是服务SLA。程序在 `source_health[].elapsed_ms` 和 `timing.total_elapsed_ms` 中记录每次真实耗时，便于持续区分 VPN/DNS 抖动与 Agent 推理耗时。
