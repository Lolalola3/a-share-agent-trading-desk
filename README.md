# A股人类交易员式 Trading Desk

本项目是本地、可审计、仅分析不自动下单的沪深主板交易台。Agent 负责解释盘面与提出建议；确定性程序负责账户、T+1、资金/股份锁定、行情新鲜度、计时器、监控防抖和归档。

## 动态日任务

- 北京时间每日第一次进入 Codex 项目时，SessionStart hook 提示创建或复用唯一的 `A股交易台 YYYY-MM-DD` 任务。09:15 前只登记任务并在本地静默等待，不拉取行情、不执行分析。
- 09:15–09:30 使用独立盘前/集合竞价协议，不请求分钟分时、不套用盘中入场逻辑，也不生成立即执行的盘中委托；09:30 起才进入盘中协议。
- 每轮分析结束后启动一个纯计时worker；它只读取本地时间和令牌，到期时才向当日任务发送一次请求，绝不拉取行情。用户主动分析后旧令牌失效，并从本轮完成时间重新计算60分钟。
- 已选择监控规则时另启独立monitor worker，以Python进程内HTTP静默检查腾讯行情，不调用curl.exe；只有实际跨越阈值时才提前唤醒任务。timer与monitor使用不同状态文件和进程生命周期，监控和分析均不连接券商、不自动下单。
- 收盘回合先执行一次新的收盘时点分析，再复核当日分析、委托反馈和监控信号，最后给出下一交易日的三情景预期与条件行动计划；全部结构化归档后才暂停计时器。
- 不再暴露或使用 09:08、09:22 等八个固定节点。

## 数据可信边界

- 盘中持仓、候选股、指数、分时和日 K 只使用腾讯。腾讯失败、过期或缺字段时标为 `tradeable=false`，不自动切换个股数据源。
- 板块独立读取腾讯申万二级行业接口直接提供的总体涨跌幅、成交额、主力净流入、上涨家数/总家数、领涨股以及5/20/60日等多周期涨跌。项目不保存板块成分快照，不批量拉取全部成分行情，也不在本地重算板块均值、广度或个股排名。
- 腾讯板块总体请求失败、关键字段不全或腾讯指数未确认当前交易日时，板块硬条件不可用；09:30前返回值只作前收盘背景，不能触发候选买入。

## 输出与监控

每次分析按“事实 → 解读 → 规则 → 结论”展示逻辑。交易建议必须由 `order_intent_create` 登记，并严格输出：

```text
时间，股票，买/卖精确价格，买卖数量，反馈等待时间
10:35-10:40，600000 浦发银行，买 10.230 元，100 股，等待反馈至 10:45
```

Agent 每轮可从 `monitoring/templates.json` 选择价格突破/跌破、涨跌幅、VWAP 和相对沪深300规则。信号只触发重新分析，不自动下单；跨越、冷却和 rearm 避免重复唤醒。

## 入口

- Agent 协议：`prompts/session_bootstrap.md`、`daily_session.md`、`monitoring.md`、`data_acquisition.md`、`global_policy.md`
- 运行配置：`config/runtime.json`
- 临时数据包：`python -m trading_desk.cli analysis-packet --trigger manual --ephemeral`
- 查看账户：`python -m trading_desk.cli account`
- 查看日任务：`python -m trading_desk.cli session --date YYYY-MM-DD`
- 测试：`python -m pytest -q`

Codex 应用和电脑需要处于可运行状态。本地唤醒器通过令牌实现可重置单次投递，不依赖 5 分钟 Codex 聊天心跳。SessionStart hook 能在打开项目后的首轮 Agent 交互中触发启动协议，但不能在没有 Agent 回合时自行创建任务。
